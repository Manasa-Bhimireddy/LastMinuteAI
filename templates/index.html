LLM API Configuration

EduSphere AI supports both Groq (extremely fast Llama models) and Google Gemini. Save your key below to activate the platform.

How to obtain a key:
  • Groq Key: Go to the Groq Console , navigate to API Keys, and generate a key starting with gsk_.
  • Gemini Key: Go to Google AI Studio , click "Get API Key", and create one.

Your API key is saved locally in a secure `.env` file within the application directory, so you only have to configure it once.
